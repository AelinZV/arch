## Описание модулей Ип-311 Илья и Руслан

### `myTerm`
Модуль `myTerm` предоставляет функции для работы с текстовым терминалом, включая:
- Очистку экрана.
- Управление курсором.
- Установку цветов текста и фона.

### `myBigChars`
Модуль `myBigChars` реализует функции для работы с большими символами и псевдографикой:
- Вывод больших символов.
- Управление позициями в больших символах.
- Рисование рамок и других графических элементов.

### `src`
Модуль `src` содержит основные компоненты симулятора:
- **Память**: Управление оперативной памятью.
- **Регистры**: Управление регистрами симулятора.
- **Команды**: Реализация набора команд для симулятора.
- **Ввод-вывод**: Функции для взаимодействия с пользователем.

### `console`
Модуль `console` содержит основную программу для запуска симулятора и утилиту для генерации шрифта:
- `main.c`: Основная программа.
- `font.c`: Генерация шрифта для больших символов.
